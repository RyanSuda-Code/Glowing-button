# Glowing Button Project

This project demonstrates glowing buttons with hover effects using HTML and CSS. The design features smooth animations and a pulsing glow effect around the buttons.

## Overview

This project was created as part of a tutorial I followed on YouTube. It helped me understand:

- CSS pseudo-elements (`::before` and `::after`)
- Absolute and relative positioning
- Hover animations with `@keyframes`
- Flexbox layout for button placement
- Using `gap` and `margin` for spacing elements

The buttons feature a glowing effect when hovered, along with a smooth pulsing animation.
